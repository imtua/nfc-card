# ImtCard!

![demo](assets/readme/0%20first.png)

ImtCard is a digital NFC business card that has a LED on it. The copper ring or the NFC antennas actually harvest some electricity through its antenna from the phone or device and with that harvested electricity, the LED lights up, how cool is that!

I made this as a reference/example card for <a href="https://jams.hackclub.com/jam/hacker-card"><b>hacker card</b></a>, a program where you can learn how to make your own hacker card and get it for free. It contains an implementation of every common parts.

## Features:
- Runs on NFC technology.
- Can store a little data in it.
- Can light up a LED through harvesting electricity.
- Cool design!
